# AI 客服的数据流向与个人资料说明（PDPA）

> 适用于：Acuven WhatsApp AI 客服演示系统（chatbot.acuventech.com）· 更新：2026-09-17 · [English](data-flow-pdpa.en.md)

## 一句话

您客人的资料存在 **Acuven 托管、位于马来西亚的服务器**上（ERP、CRM 等后台也在这里）。只有需要 AI 处理时（例如生成回复），才会把对话发给 AI 服务商。按服务商的商业条款，这些内容**默认不用于训练模型**。

## 客人发一条消息，数据经过哪里

```
客人手机 WhatsApp ──► Meta（WhatsApp 官方接口）──► 本系统服务器 ──► Anthropic（Claude，生成回复）
                                                    │          └─► OpenAI（只有语音消息：转成文字）
                                                    ├─► ERP 系统（查库存、开订单、开电子发票）
                                                    └─► CRM 系统（建联系人、记商机）
```

网页聊天不经过 Meta，也不收语音。

## 存了什么、存在哪、存多久

| 数据 | 存放位置 | 留存 |
|---|---|---|
| 当前对话记忆：手机号、称呼、语言、最近 20 轮对话 | 本系统服务器（Redis） | 最后一次对话后 **7 天自动删除** |
| 完整对话记录、每次工具调用的输入输出、用量费用 | 本系统服务器（MySQL） | **目前不会自动删除** |
| 客户资料、订单、电子发票 | ERP 系统 | 随 ERP 的业务数据保留 |
| 联系人、商机、跟进记录 | CRM 系统 | 随 CRM 的业务数据保留 |
| 餐饮订单、看房预约、酒店预订、支持工单（姓名、电话、地址、入住日期、客人描述的问题） | 本系统服务器（MySQL） | 目前不会自动删除 |
| 服务器运行日志（含手机号，个别情况含客人原话） | 本系统服务器 | 按大小滚动覆盖（最多约 30MB），每次系统更新时清空 |
| 客人发来的图片、PDF、语音 | **不存盘**。图片只在当轮使用；PDF 在内存里暂存（每人最多 5 份），客人发 menu 重新开始或服务器重启即消失；语音转成文字后原音频丢弃 | — |

## 第三方服务商会拿到什么

| 服务商 | 用途 | 收到的内容 | 服务商的政策（官方原文要点） |
|---|---|---|---|
| **Anthropic**（Claude） | 理解问题、生成回复 | 对话记录、客人资料摘要（手机号、称呼等）、查询 ERP/CRM 的结果、客人发来的图片和 PDF | API 数据**默认不用于训练**；输入输出在 **30 天内删除**；被判定违反使用政策的内容最长保留 2 年 |
| **OpenAI**（Whisper） | 语音转文字 | 语音消息的音频 | API 数据**默认不用于训练**；官方文档列明语音转录接口**不保留滥用监控日志** |
| **Meta**（WhatsApp） | 收发消息 | WhatsApp 上的所有消息和媒体 | 消息和媒体在 Meta 侧最长保留 **30 天** |

以上三家的服务器都不在本系统上，可能位于马来西亚境外。

**电子发票（LHDN MyInvois）**：演示环境的发票校验是**模拟**的，发票资料不会发送给 LHDN。正式启用 MyInvois 后，ERP 会按 LHDN 的要求提交买方的名称、TIN、地址、电话和电邮。

## 谁能看到

- **Acuven 的演示管理人员**：用管理后台（「导演台」）的访问密钥，可以查看所有对话记录和工具调用，也可以人工接管、代为回复。同一把密钥能打开演示后台（`/admin`），列出所有餐饮订单、看房预约、酒店预订和支持工单，连同上面的姓名电话。网页聊天同样需要这把密钥，没有密钥打不开，也就无法输入手机号调出别人的对话
- **服务器管理员**：能直接访问服务器上的数据库和日志
- **有 ERP / CRM 账号的人**：能看到 AI 写进这两个系统的客户、订单和跟进记录
- 客人本人：WhatsApp 上看到自己的对话

## 演示版目前的限制（请知悉）

本系统目前是**演示环境**，以下几点和正式上线的标准不同，签约部署时需要补齐：

1. **完整对话记录没有自动删除**，只能由我们人工删除
2. **没有让客人自助删除资料的入口**。客人要求查阅、更正或删除时，由我们人工处理。对外的说明页是 [chatbot.acuventech.com/privacy](https://chatbot.acuventech.com/privacy)（Meta App 的 Privacy Policy / Data deletion 两个 URL 填的就是它），页面让客人发 WhatsApp 提出申请；bot 收到这类请求一律转人工，不会自己答应删（2026-09-16 起）
3. **查询和下单只认渠道确认的号码**：AI 只按客人发消息用的那个 WhatsApp 号码查 ERP / CRM、下单、开发票；在对话里报出别人的手机号、公司名或客户编号，查不到也下不了单，AI 会转人工（2026-09-16 起）。仍需知悉的前提是：**谁在用这个 WhatsApp 号，谁就被当作这个客人**，我们不做第二重验证；客人若在 WhatsApp 里隐藏了号码，我们无法确认身份，只能记下联系方式转人工
4. 演示环境的 ERP、CRM 是共用的演示系统，里面的数据会被不定期清理，**请勿输入真实客户资料**
